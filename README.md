# ZapretGUI
Простой графический интерфейс для утилиты Zapret на чистом Python (Tkinter). Запуск обхода в один клик, вывод PID и статуса. Portable-версия. Внимание: из-за отсутствия цифровой подписи Windows SmartScreen может выдать предупреждение при запуске. сделано arutt228-bit за 3 часа на коленке
