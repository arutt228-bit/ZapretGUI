# Zapret GUI Control v1.0

Максимально простой, понятный и удобный графический интерфейс для утилиты **Zapret**. Написан на **чистом Python** с использованием встроенной библиотеки **Tkinter** (без тяжелых сторонних фреймворков и библиотек).

Программа автоматизирует всё в один клик: запускает обход блокировок, показывает динамический статус работы, выводит системный PID запущенного процесса и позволяет принудительно всё закрыть одной кнопкой, если служба зависла.

---

   ✨ Основные особенности приложения:
* 🪶 **Чистый Python**: Никакого лишнего мусора внутри, программа работает быстро, предсказуемо и весит по минимуму.
* 📦 **Полный Portable**: Интерфейс сам бережно распаковывает нужные базовые файлы `zapret` в свою рабочую папку и обращается к ним локально. Программа не мусорит в системе и не лезет на системный диск C без вашего ведома.
* 🟢 **Удобный UX**: Встроенный мониторинг статуса (зеленый/красный цвет), кнопка быстрого перехода на YouTube-канал автора и кнопка моментального открытия папки с бинарниками из меню «Информация».

---

   ⚠️ Важное предупреждение (Прочитай перед запуском!)

Так как программа скомпилирована в один ".exe" никому не известным человеком(мной) и у неё нет дорогой цифровой подписи (Code Signing Certificate), встроенная защита Windows будет паниковать:

1. **Синее окно SmartScreen**: При первом запуске операционная система почти стопроцентно выдаст окно с текстом *"Система Windows защитила ваш компьютер"* или *"Неизвестный издатель"*. 
   **Что делать**: Это абсолютно нормально для бесплатного софта. Нажмите кнопку **«Подробнее»**, а затем — **«Выполнить в любом случае»**. Со временем, когда программу скачают другие люди, это предупреждение исчезнет.
2. **Права администратора**: Программа автоматически запрашивает повышенные привилегии (UAC). Это необходимо, так как системный сетевой драйвер `WinDivert` физически не может перехватывать пакеты и менять трафик из-под обычной учетной записи.

---
